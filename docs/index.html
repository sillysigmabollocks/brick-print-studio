Brick Print Studio Elegoo Centauri Carbon 2

LEGO set to 3MF

Generate print plates grouped by LEGO color, with the required copies already placed. Minifigures and their dedicated parts are excluded.

Generate a set on GitHub

Open the generator, select Run workflow, and enter your LEGO set number. GitHub will build the plates and reports.

Open generator on GitHub

Publish this page from the repository’s docs folder on GitHub Pages.

Download your print plates

Open the newest run and select Download the Print ZIP in its summary. In the ZIP, open the 3MF files under Printing_Batches in your slicer.

GitHub sign-in and repository write access are required to run the generator.
